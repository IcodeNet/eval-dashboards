# Teach Exercises: Foundations to First Iteration Loop

These are hands-on, artifact-first exercises. Each one states the concept it
teaches, the question it answers, and a concrete goal before any commands.

Use these exercises after (or alongside) [docs/teach-curriculum.md](../teach-curriculum.md),
which frames the full novice path. For delivery-stage / release workflows,
continue on to [docs/teach-labs/](../teach-labs/README.md) after finishing here.

1. [Exercise 01: Foundations (plain language)](./01-foundations.md)
2. [Exercise 02: Build a minimal eval artifact](./02-artifact-first.md)
3. [Exercise 03: Add first synthetic dataset rows](./03-first-synthetic-dataset.md)
4. [Exercise 04: Upgrade one row to taxonomy-complete](./04-row-taxonomy.md)

## Where to go next

Once you can complete one iteration loop (Exercise 10) and diagnose a red
run (Exercise 11), move to [docs/teach-labs/](../teach-labs/README.md) for
release-stage workflows (pre-PR gating, PR review triage, release
readiness, post-release monitoring, FDE role workflow).
